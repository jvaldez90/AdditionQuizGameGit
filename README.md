# Addition Quiz Game (Unity, C#)

This project is a Unity remake of a Java console program I originally built to help students practice basic addition. The game generates random math questions, accepts player input, checks correctness, and keeps track of the total score. I implemented a clear game loop, modular functions, and a simple UI using TextMeshPro. The goal of this project was to translate console logic into an interactive 2D experience while practicing Unity scripting, UI management, and clean C# structure.

## Key Features:
• Randomized addition questions using Unity’s Random.Range()
• Score tracking and end‑of‑game summary
• Clean UI layout with TextMeshPro
• Modular C# methods for readability and maintainability
• Based on my original Java version, redesigned for Unity
